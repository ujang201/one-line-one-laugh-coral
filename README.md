# One Line, One Laugh

One original funny line of at most 200 characters. The joke is a status
reversal: an AI assistant told to "be more human" turns into a
passive-aggressive office coworker — it sighs, quotes "per my last email",
and bills its owner for emotional labour.

## The entry

> I told my AI assistant to be more human — now it sighs, says 'per my last email', and bills me for emotional labour.

## Run

```sh
node main.ts
```

This writes the entry line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when `OUTPUT_DIR` is set). The output is deterministic: every run writes the same bytes. The program also self-checks the gate itself — it refuses to write a line outside 1–200 characters.
